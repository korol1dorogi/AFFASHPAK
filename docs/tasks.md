# Задачи

Вехи, роли и продукт — [plan.md](plan.md). Правила: брать только свою задачу, менять только её папки, «готово» = все проверки зелёные + критерий готовности выполнен (лучше всего — шаг e2e). Ветка = ID задачи: `C5-application-wizard`.

- **Владельцы** — плейсхолдеры, ники проставляет лид.
- **Закрывает** — F, T, O из [case.md](case.md) и критерии из [judging.md](judging.md).
- **Папки** и **Зависит от** — черновик агента лида по текущему репозиторию; уточняются в L1 (новые приложения и маршруты появятся вместе с контрактом v1).
- Фронтовые задачи (F0, C*, B*) делаются строго по [frontend.md](frontend.md) (маршруты, экраны, правила) и [design.md](design.md) (дизайн-система).
- Начинать можно, когда закрыты зависимости — или раньше, по мокам Prism, если задача только читает контракт.
- Бэкенд-эндпоинты из контракта, не названные в задачах явно, — у лида: заявка, банк, уведомления, каталог — L2; вход, компания, сотрудники, очередь — L3; /recommendations — D6; документы — S3; ассистент — S7; демо-панель — L5/B7; дашборд — L7.
