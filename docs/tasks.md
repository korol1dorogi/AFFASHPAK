# Задачи

Вехи, роли и зоны ответственности — [plan.md](plan.md). Задачи T1…Tn нарезаются после кейса (2–6 часов каждая).
Правила: брать только свою задачу, менять только её папки, «готово» = все проверки зелёные + критерий готовности выполнен (лучше всего — шаг e2e).

## Формат задачи
```
## T7 — Форма заявки
Закрывает: F3
Владелец: {имя}
Папки: frontend/src/features/application-form/, e2e/journey.spec.ts (шаг 3)
Зависит от: T2
Готово, когда: шаг 3 в e2e/journey.spec.ts зелёный
Статус: не начато | в работе | ревью | готово
```
