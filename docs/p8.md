**Заминки:**

1. **Порт 8080 закрыт самой Windows.** `docker compose up` упал: `ports are not available: … 127.0.0.1:8080 … forbidden by its access permissions`. Порт не занят программой — он в зарезервированном диапазоне Windows (Hyper-V/WSL). В README был только текст `port is already allocated`, и человек мог не узнать свою ошибку. **Исправлено:** строка в «Если что-то не так» дополнена этим текстом и командой `netsh interface ipv4 show excludedportrange protocol=tcp`; решение то же — `WEB_PORT=8081`.
2. **Новая копия подхватила базу старой.** Имя проекта Compose зашито в `docker-compose.yml` (`name: alfa-cabinet`), поэтому вторая копия репозитория на той же машине стартует на томе первой — со старыми заявками. На чистой машине жюри этого нет, но у команды и у жюри с двумя копиями — путаница. **Исправлено:** строка в «Если что-то не так» — `docker compose -p <имя> up …` или `down -v` в старой копии.

**Итог:** README проходится; первая сборка и старт ≈ 2 минуты, как и написано; память в покое ~0,5 ГБ, как и написано; все сценарии зелёные.
